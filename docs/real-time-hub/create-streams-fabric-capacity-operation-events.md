# Get Fabric capacity operation events in Real-Time hub

This article describes how to get Fabric capacity operation events as an eventstream in Fabric Real-Time hub.

Fabric capacity operation events are events generated by a Fabric capacity that report per-operation capacity unit (CU) consumption, duration, throttling delay, and status for every operation that consumes capacity.

With Fabric eventstreams, you can capture these Fabric capacity operation events, transform them, and route them to various destinations in Fabric for further analysis. This seamless integration of Fabric capacity operation events within Fabric eventstreams gives you granular visibility into which workspaces, items, workloads, and identities are consuming CU on your capacity.

> [!NOTE]
> For Data Warehouse customers looking for more granular consumption insights, see [Warehouse consumption and utilization in Microsoft Fabric](../data-warehouse/usage-reporting.md) for guidance.

## Event types
Here are the supported Capacity operation events:

| Event type name | Description |
| --------------- | ----------- |
| Microsoft.Fabric.CapacityOperationEvents.Operation | Emitted for every operation that consumes capacity. |

For more information, see [Explore Capacity operation events](explore-fabric-capacity-operation-events.md).

## Prerequisites

- Access to a workspace in the Fabric capacity license mode or the Trial license mode with Contributor or higher permissions.  
- A Fabric capacity where you have capacity admin role.

## Create streams for Fabric capacity operation events

You can create streams for Fabric capacity operation events in Real-Time hub by using one of the following methods:

- [Using the **Data sources** page](#data-sources-page)
- [Using the **Fabric events** page](#fabric-events-page)

## Data sources page

[!INCLUDE [launch-get-events-experience](./includes/launch-get-events-experience.md)]

5. On the **Data sources** page, select the **Fabric events** category at the top, and then select **Connect** on the **Capacity operation events** tile.

    Now, use the instructions from the [Configure and create an eventstream](#configure-and-create-an-eventstream) section.

## Fabric events page

1. In Real-Time hub, select **Fabric events** on the left navigation menu.
1. Move the mouse over **Capacity operation events**, and select the **+** (plus) link, or select **... (ellipsis)** and then select **Create Eventstream**.

    :::image type="content" source="./media/create-streams-fabric-capacity-operation-events/create-menu.png" alt-text="Screenshot that shows the Fabric events page with Capacity operation events selected." lightbox="./media/create-streams-fabric-capacity-operation-events/create-menu.png":::

    Now, use the instructions from the [Configure and create an eventstream](#configure-and-create-an-eventstream) section, but skip the first step of using the **Add source** page.
