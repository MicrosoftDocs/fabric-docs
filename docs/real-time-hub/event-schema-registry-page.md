# Explore the Event schema registry page in Fabric Real-Time hub

Use the **Event schema registry** page in Real-Time hub to find and open the event schema sets and schemas you have permission to access across your tenant.

To open the page, select **Event schema registry** on the left navigation menu in Real-Time hub.

:::image type="content" source="../real-time-intelligence/schema-sets/media/create-manage-event-schemas-real-time-hub/event-schemas.png" alt-text="Screenshot that shows the Event schema registry with an expanded schema set and its schemas." lightbox="../real-time-intelligence/schema-sets/media/create-manage-event-schemas-real-time-hub/event-schemas.png":::

## Explore schema sets and schemas

The page lists event schema sets. Expand a schema set to see its schemas. From the list, you can:

- Preview a schema definition without leaving the page.
- Open a schema to inspect its definition and versions.
- Open a schema set to manage the collection.

## Search and filters

Use the search box to find a schema or schema set. Use the available filters, such as workspace, to narrow the list. The page only shows items you have permission to access.

## Schema actions

From the **Event schema registry** page, you can create a schema or import Avro definitions into a new or existing schema set. For step-by-step instructions, see [Create and manage event schemas in Real-Time hub](../real-time-intelligence/schema-sets/create-manage-event-schemas-real-time-hub.md) and [Import event schemas](../real-time-intelligence/schema-sets/import-event-schemas.md).
