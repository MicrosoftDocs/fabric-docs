title: Event consumer region requirement
description: Same-region requirement for consuming region-scoped event groups.
ms.topic: include
ms.date: 10/13/2026
ai-usage: ai-assisted
---

> [!NOTE]
> Cross-region event configuration isn't supported for this event group. The event consumer item (such as Activator or Eventstream) must be in the same region as the event source.
