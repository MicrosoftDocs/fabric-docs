---
title: Business event consumer region requirement
description: Same-region requirement for consuming Business events.
ms.topic: include
ms.date: 10/13/2026
ai-usage: ai-assisted
---

> [!NOTE]
> Cross-region event configuration isn't supported for Business events. The event consumer item (such as Activator or Eventstream) must be in the same region as the Event Schema Set item that contains the business event.
