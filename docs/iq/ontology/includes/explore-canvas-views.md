## Explore canvas views

The home configuration canvas of ontology contains three views: [full ontology](#full-ontology), [lineage](#lineage), and [relationship](#relationship).

### Full ontology

The **Full ontology** view of the canvas shows all entity types and relationships present in the ontology. Select an entity type from the **Explorer** to center it in the canvas window.

:::image type="content" source="../media/tutorial-3-preview-ontology/canvas-full-ontology.png" alt-text="Screenshot of the full ontology canvas view." lightbox="../media/tutorial-3-preview-ontology/canvas-full-ontology.png":::

### Lineage

The **Lineage** view of the canvas shows the inheritance structure of entity items. Select an entity type from the **Explorer** to show it in the canvas along with any inheritance relationships.

:::image type="content" source="../media/tutorial-3-preview-ontology/canvas-lineage.png" alt-text="Screenshot of the lineage canvas view." lightbox="../media/tutorial-3-preview-ontology/canvas-lineage.png":::

### Relationship

The **Relationship** view of the canvas shows the relationships of entity items. Select an entity type from the **Explorer** to show it in the canvas along with any modeled relationships.

:::image type="content" source="../media/tutorial-3-preview-ontology/canvas-relationship.png" alt-text="Screenshot of the relationship canvas view." lightbox="../media/tutorial-3-preview-ontology/canvas-relationship.png":::
