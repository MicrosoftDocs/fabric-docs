# Ontology (preview) tutorial part 5: Conclude and clean up resources

In this tutorial, you modeled the Lakeshore Retail scenario, in which a multi-region retailer balances product availability, waste, and safe cold-chain operations across stores supplied by regional distribution centers. You created an ontology with bound data and contextual enrichment, explored it with the canvas, entity type, and graph views, and used the ontology agent to identify high-priority stores in the West that need intervention.

Next, delete the resources you created during the tutorial.

[!INCLUDE [Fabric feature-preview-note](../../includes/feature-preview-note.md)]

## Clean up resources

When you finish the tutorial, use the steps in this section to delete all the resources you created.

* Delete your Fabric workspace under **Workspace settings** > **Remove this workspace**. This action deletes everything inside the workspace, including the sample data lakehouse, eventhouse, semantic model, ontology (preview) item and its associated data and graph model.

    :::image type="content" source="media/tutorial-5-conclusion/delete-workspace.png" alt-text="Screenshot of deleting a Fabric workspace." lightbox="media/tutorial-5-conclusion/delete-workspace.png":::

* Remove the sample data files you downloaded from your local machine.
