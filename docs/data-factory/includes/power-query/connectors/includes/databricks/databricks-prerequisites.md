This connector is only for use with a Databricks SQL Warehouse running on AWS and using OAuth. If you're using Azure Databricks, use the [Azure Databricks](/power-query/connectors/databricks-azure) connector. If you aren't using OAuth with your Databricks SQL Warehouse (on AWS or GCP), use the [Azure Databricks](/power-query/connectors/databricks-azure) connector too. Databricks Community Edition isn't supported.
