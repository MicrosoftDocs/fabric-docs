# Create Fabric apps with Power BI Desktop for Apps (preview)

Power BI Desktop for Apps is a way for data analysts, report creators, and others who want to build custom Fabric apps through conversation. Describe who the app is for and what they need to do in everyday language. Power BI Desktop for Apps generates the app and lets you preview and refine it locally through chat. When you're ready to share it, publish it to a Fabric workspace.

Power BI Desktop for Apps is a separate application that you can launch from Power BI Desktop or open directly after installation. It provides another way to create Fabric apps based on the [data app template](data-apps-template.md), without setting up the SDK and CLI developer workflow.

> [!NOTE]
> You don't need to install developer tools separately or set up the SDK and CLI workflow. Power BI Desktop for Apps handles the app-building environment so you can focus on the data and what your app needs to do.

Connect existing semantic models hosted in the Power BI service to use their data and business definitions in your app.

For an introduction to the app-building experience and its current limitations, see [What is Power BI Desktop for Apps (preview)?](/power-bi/create-reports/desktop-for-apps/overview)
