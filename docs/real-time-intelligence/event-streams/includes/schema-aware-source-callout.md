> [!NOTE]
> In a **schema-aware Eventstream (Preview)**, you can choose a classifier
> column (a classifier or discriminator field) for unschematized events with
> different shapes, or keep the source untyped and combine it with schematized
> events in the same Eventstream. For supported sources, you can also associate
> the source with a registered schema. For more information, see
> [Schema-aware Eventstreams overview (Preview)](../schema-aware-eventstreams-overview.md).
