# Schema Registry region availability

Event schema sets are generally available across all regions where Fabric and related workloads are enabled. 

Use [Fabric region availability](../../admin/region-availability.md) for the current regional availability of Fabric capacities and workloads. Plan your deployment around the Fabric services your solution uses, including the workspace that contains the event schema set and the eventstream's sources and destinations.

## Plan a deployment

Your tenant's [home region](../../admin/find-fabric-home-region.md) and the location of its Fabric capacities affect where you can use Fabric workloads. For information about using capacities in another region, see [Multi-Geo support for Fabric](../../admin/service-admin-premium-multi-geo.md).
